# Optional extras

Reference solutions for the optional extras. This module stands alone: it uses only the stage 1 domain, with
`@optics` added.

- `optics/OpticUpdates.kt`: lenses generated by the Arrow 2.3 optics **compiler plugin** (`io.arrow-kt.optics`).
- `racing/Tracking.kt`: first *successful* response from two redundant providers with `raceN`.
- `stm/PickupSlots.kt`: pickup slot reservations with `TVar` and `atomically` (`arrow-fx-stm`).
- `saga/Booking.kt`: reserve → charge → pickup, compensated in reverse order with `saga { }.transact()`.

```bash
./gradlew :09-extras:test
```
